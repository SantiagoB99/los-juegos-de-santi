# Los Juegos de Santi 🎲

Tracker personal de juegos de mesa. Guardá tu colección, registrá partidas y seguí las estadísticas con tus amigos.

**[→ Abrir la app](https://santiagob99.github.io/los-juegos-de-santi/)**

---

## Funcionalidades

- **Colección** — Buscá juegos en BoardGameGeek y añadílos con su estado (tengo, quiero, jugué)
- **Partidas** — Registrá cada partida con fecha, lugar, jugadores, foto y notas
- **Amigos** — Llevá el ranking de quién gana más
- **Dashboard** — Estadísticas: juego favorito, rival más frecuente, rachas y más
- **Sin cuenta** — Todo queda guardado en tu navegador, sin servidores ni registro

## Correr localmente

```bash
npm install
npm run dev
```

Abre en `http://localhost:5173`

## Tecnologías

React · Vite · Zustand · Tailwind CSS · BoardGameGeek API
